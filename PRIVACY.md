## 🔎 What This Document Covers

This document describes how Universum Infinitum: Galaxy Sizes at https://github.com/hmlendea/stellaris-ui-galaxy-sizes handles personal data. It covers the application behaviour and verified integrations described below. Where the software is self-hosted, the instance operator may have separate responsibilities described below.

## 📥 Data We Handle

### Data Provided to the Application

- No personal data is requested by this mod. Its files provide galaxy-size scenarios and generation settings to Stellaris.

### Data Generated or Collected by the Application

- This mod does not generate or automatically collect personal data, telemetry, diagnostics, or usage data.

### Data Received from Integrations

- This mod does not receive personal data from integrations or third parties.

## 🧭 Processing and Use

The application processes the data described above for these verified functions:
- Provide additional galaxy-size scenarios and generation settings — scenario configuration files; no personal data is involved.
- Provide English names for the added scenarios — localisation strings; no personal data is involved.

## 🗄️ Storage, Retention, and Deletion

The mod contains no account, database, telemetry, or user-data storage component. Its scenario and localisation files are installed where Stellaris or the chosen mod platform stores them. This mod does not define retention or deletion of personal data. Any personal data, logs, or backups handled by Stellaris or a distribution platform are outside this mod and are controlled by the relevant provider or operator.

## 🔗 External Processing and Integrations

The mod has no built-in external data transfer or integration that receives personal data. Distribution platforms and Stellaris may separately process information when users download, install, or play the game; those activities are outside this mod.

## 🛡️ Data Protection and Security

This repository contains game configuration and localisation files, not a service that collects or stores personal data. The mod does not define safeguards for personal data. Review the privacy and security information provided by Stellaris and the platform used to obtain or run the mod for their respective practices.

## 🔄 Document Changes

Update this document when application data flows, storage, integrations, or deployment responsibilities change. The current version is published at [PRIVACY.md](./PRIVACY.md).

## 📬 Contact

For questions about application data handling, contact the project maintainers through [GitHub Issues](https://github.com/hmlendea/stellaris-ui-galaxy-sizes/issues). For a self-hosted instance, contact the instance operator, unless the project explicitly handles the request. Include the mod version, distribution platform, and relevant data flow; do not send passwords, access tokens, or other secrets.
