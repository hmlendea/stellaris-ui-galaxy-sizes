# Quick Start

## 5-Minute Setup

### 1. Install Mod

**Steam Workshop (Recommended):**
1. Open Steam → Stellaris Workshop
2. Search "Universum Infinitum: Galaxy Sizes"
3. Click **Subscribe**
4. Launch Stellaris → Playsets → Enable mod

**Manual (GitHub Releases):**
1. Download latest `ui-galaxy-sizes.zip` from [GitHub Releases](https://github.com/.../releases)
2. Extract to Stellaris mod directory:
   - **Windows:** `%USERPROFILE%\Documents\Paradox Interactive\Stellaris\mod\`
   - **macOS:** `~/Documents/Paradox Interactive/Stellaris/mod/`
   - **Linux:** `~/.local/share/Paradox Interactive/Stellaris/mod/`
3. Launch Stellaris → Playsets → Enable mod

### 2. Start New Game

1. **New Game** → **Galaxy Size** dropdown
2. Select one of six new sizes:
   - **Minuscule** (100 stars) — Quick tests
   - **Gigantic** (1,200 stars) — Large
   - **Immense** (1,400 stars) — Very large
   - **Colossal** (1,600 stars) — Huge
   - **Titanic** (1,800 stars) — Massive
   - **Ludicrous** (2,000 stars) — Maximum
3. Choose **Galaxy Shape** (11 options)
4. Adjust **Empire Settings** (defaults scale with size)
5. **Generate Galaxy** → Play

### 3. Ludicrous Size Note

**Requires [UI Star Names](https://steamcommunity.com/sharedfiles/filedetails/?id=...) mod** for unique system names. Without it, duplicate names will occur (engine has ~1000 vanilla names).

## Size Selection Guide

| Size | Stars | Time | RAM | Best For |
|------|-------|------|-----|----------|
| Minuscule | 100 | <5s | 4GB | Testing, quick games |
| Gigantic | 1,200 | 10-20s | 8GB | Standard large |
| Immense | 1,400 | 15-30s | 12GB | Long campaigns |
| Colossal | 1,600 | 20-40s | 16GB | Epic scale |
| Titanic | 1,800 | 30-60s | 16-24GB | Maximum vanilla-like |
| Ludicrous | 2,000 | 60-120s | 24-32GB | Absolute maximum |

## Common Issues

| Problem | Solution |
|---------|----------|
| Mod not in launcher | Verify files in correct mod directory, restart launcher |
| "Mod incompatible" | Update Stellaris to 4.5.x |
| Generation crashes | Try smaller size, close other apps, check RAM |
| Duplicate names (Ludicrous) | Install UI Star Names mod |
| Sizes show as `ui_gigantic` | Reinstall mod, verify localisation file |

## Uninstall

1. Disable in Playsets
2. Delete `ui-galaxy-sizes.mod` and `ui-galaxy-sizes/` from mod directory
3. Or unsubscribe in Steam Workshop
